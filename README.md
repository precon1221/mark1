# System — Digital Design Project 2

An interactive suite of nine unified graphic icons for COMM2749 Digital Media Studio 1: Production.

## Concept

**System** is interpreted as a speculative interface for a future machine intelligence. The intended audience is science-fiction and digital-art enthusiasts. The context is an interactive gallery installation, presented as a responsive browser-based interface for desktop, tablet, and mobile.

## Interaction

Select any icon to trigger a short image-swap animation and its own original sound cue. Keyboard users can use Tab followed by Enter or Space.
